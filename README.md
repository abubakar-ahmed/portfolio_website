# Abubakar Ahmed — Portfolio

Motorsport-inspired portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Customize

Edit `src/data/portfolio.ts` to update contact info, experience, projects, skills, education, and certificates.

## Deploy

```bash
npm run build
```

Configured for GitHub Pages at `https://abubakar-ahmed.github.io/portfolio_website/`.
